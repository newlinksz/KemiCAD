# KemiCAD 使用帮助

适用版本：KemiCAD 0.9.0。KemiCAD 基于 KiCad 开源软件，下列说明同样适用于 KiCad 的对应功能。新手请先阅读 [入门指南](入门指南.md)。

## 主窗口（工程管理器）

打开/新建工程，并启动各个工具：原理图编辑器、符号编辑器、PCB 编辑器、封装编辑器、Gerber 查看器、图像转换器、PCB 计算器、图框编辑器，以及插件和内容管理器。

## 原理图编辑器

- 放置符号 `A`、电源 `P`、连线 `W`、总线 `B`、网络标签 `L`、全局标签 `Ctrl+L`、无连接标记 `Q`、文本 `T`。
- 旋转 `R`、镜像 `X`/`Y`、移动 `M`、拖动 `G`、编辑属性 `E`、删除 `Del`。
- 层次原理图：放置层次图纸 `S`，双击进入子图纸。
- 「检查 → 电气规则检查」做 ERC；「工具 → 从原理图更新 PCB」（`F8`）把改动手动同步到 PCB；PCB 编辑器的「工具 → 从 PCB 更新原理图」可反向同步受支持的属性（如位号、值、封装）。

## PCB 编辑器

- 布线 `X`、差分对布线 `6`、过孔 `V`（布线中）、切换到上一/下一铜层 `PageUp`/`PageDown`。
- 移动 `M`、旋转 `R`、翻到另一面 `F`、编辑属性 `E`。
- 填充所有铺铜 `B`、取消填充 `Ctrl+B`。
- 「文件 → 电路板配置」设置层数、线宽、间距和网络类等规则。
- 「检查 → 设计规则检查」做 DRC；「视图 → 3D 查看器」（`Alt+3`）查看 3D 效果（需已安装 3D 模型，见入门指南第 7 节）。
- 「文件 → 导出 → STEP/GLB/BREP/XAO/PLY/STL...」导出 STEP 等 3D 格式。
- 「文件 → 制造输出」生成 Gerber、钻孔、位置文件等。

## 符号库与封装库（KemiCAD 元件库）

- 安装包自带 KemiCAD 元件库：符号库在安装目录 `share\kicad\symbols`，封装库在 `share\kicad\footprints`。
- 「设置 → 管理符号库 / 管理封装库」：添加、移除或启用/禁用库。分为全局库（所有工程可用）和工程专用库。
- 用「符号编辑器」「封装编辑器」创建自己的元件，建议保存在自建库中，不要直接修改自带库。
- 3D 模型未随安装包提供，见入门指南第 7 节。

## 插件和内容管理器（PCM）

在主窗口打开「插件和内容管理器」，可从 KiCad 官方内容仓库安装插件、库和颜色主题。插件来自第三方，请自行判断是否可信。

## 快捷键

- 通用：缩放 `F1`/`F2` 或滚轮，适合屏幕 `Home`，撤销 `Ctrl+Z`，重做 `Ctrl+Y`，查找 `Ctrl+F`，保存 `Ctrl+S`。
- 查看全部快捷键：`Ctrl+F1` 或「帮助 → 快捷键列表」。快捷键可在「设置 → 偏好设置 → 快捷键」中修改。

## 文件格式

| 扩展名 | 内容 |
| --- | --- |
| `.kicad_pro` | 工程文件 |
| `.kicad_sch` | 原理图 |
| `.kicad_pcb` | PCB |
| `.kicad_sym` | 符号库 |
| `.pretty` 文件夹 / `.kicad_mod` | 封装库 / 封装 |
| `.kicad_wks` | 图框 |
| `.gbr`、`.drl` | Gerber、钻孔输出 |

KemiCAD 的文件与对应版本的 KiCad 兼容，也可通过「文件 → 导入」导入部分其他 EDA 软件的工程。

## 常见问题

- **找不到某个元件？** 在放置符号对话框中用关键字搜索；仍没有可用符号编辑器自建，或通过「管理符号库」添加其他库。
- **3D 查看器里元件没有模型？** 安装包不含 3D 模型，见入门指南第 7 节。
- **帮助菜单打开的是网页？** 帮助和入门指南会打开本项目 GitHub 页面，文档就在仓库 `docs/kemi` 目录。
- **更新原理图后 PCB 没变化？** 需要在原理图中执行「从原理图更新 PCB」（`F8`）。
