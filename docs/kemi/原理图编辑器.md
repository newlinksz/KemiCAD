# 原理图编辑器（适用版本：KemiCAD 0.9.x）

原理图编辑器用于放置符号、连接电路、检查电气规则，并将设计交给 PCB 编辑器。
本文使用当前中文菜单名称。

## 开始绘图

建议从工程管理器打开工程中的原理图，以便使用工程关联功能。

1. 选择「文件 → 原理图配置」，检查原理图设置。
2. 选择「文件 → 页面设置」，设置图纸信息。
3. 绘图过程中使用「文件 → 保存」保存修改。

从工程管理器启动与独立启动时，「文件」菜单的内容有所不同。
独立启动时提供「新建」「打开」及「打开最近使用」；工程模式提供「将当前图纸另存为」。

## 放置符号与连接

1. 选择「放置 → 放置符号」，添加电路元件。
2. 选择「放置 → 放置电源符号」，添加电源符号。
3. 选择「放置 → 拖动连线」，绘制连接导线。
4. 按需要添加「放置网络标签」或「放置全局标签」。

「拖动连线」是当前界面中绘制导线命令的中文名称。
需要明确标记不连接的引脚时，使用「放置 → 放置/移除无连接标志」。

## 总线与层次图纸

- 「放置 → 绘制总线」用于绘制总线。
- 「放置 → 放置连线至总线入口」用于添加总线入口。
- 「检查 → 显示总线语法」可查看总线语法说明。
- 「放置 → 绘制层次图纸」用于建立层次图纸。
- 「放置 → 放置层次标签」及「从图纸放置引脚」用于层次连接。
- 「放置 → 同步所有图纸引脚」用于同步图纸引脚。

通过「视图 → 面板 → 层次导航」显示或隐藏层次导航。
「视图」菜单还提供「上一图纸」「下一图纸」和「向上导航」。

## 整理与检查电路

1. 使用「工具 → 批注原理图」填写符号位号。
2. 使用「工具 → 批量编辑符号字段」集中整理符号字段。
3. 打开「检查 → 电气规则检查 (ERC)」检查电气规则。
4. 根据检查结果核对连接、引脚及其他问题。

「视图」菜单提供「显示 ERC 错误」「显示 ERC 警告」和「显示 ERC 排除」。
修改电路后再次检查，并结合电路用途复核设计。

## 分配封装并更新 PCB

1. 选择「工具 → 分配封装」，为需要上板的符号分配封装。
2. 返回原理图后保存修改。
3. 选择「工具 → 从原理图更新 PCB」，将原理图变更交给 PCB 编辑器。
4. 使用「工具 → 切换到 PCB 编辑器」继续布局布线。

独立打开原理图时，「从原理图更新 PCB」处于禁用状态。
需要使用此功能时，应从工程管理器打开关联工程。

## 符号与显示面板

- 「视图 → 符号库浏览器」用于浏览库符号。
- 「设置 → 管理符号库」用于维护符号库列表。
- 「工具 → 与库符号同步」用于更新原理图中的库符号。
- 「检查 → 将符号与库符号进行比较」用于查看差异。
- 「视图 → 面板」中的「属性」和「搜索」可按需打开。

## 输出与保存

- 「文件 → 打印」用于打印原理图。
- 「文件 → 绘制」用于打开绘制输出功能。
- 「文件 → 导出 → 网表」用于导出网表。
- 「文件 → 导出 → 符号」用于导出原理图中的符号。
- 「工具 → 生成物料清单」用于生成物料清单。

输出前检查图纸内容、符号字段和封装分配，并保存当前修改。
