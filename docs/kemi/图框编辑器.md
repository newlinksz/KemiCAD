# 图框编辑器（适用版本：KemiCAD 0.9.x）

图框编辑器用于制作和维护图纸边框、标题栏及其他图框内容。
图框保存为 `.kicad_wks` 文件，可供原理图和 PCB 图纸使用。

## 新建或打开图框

1. 选择「文件 → 新建」，开始制作图框。
2. 编辑已有文件时，选择「文件 → 打开」。
3. 也可从「文件 → 打开最近使用」中选择近期文件。
4. 使用「文件 → 保存」保存修改。
5. 如需保留原文件，使用「文件 → 另存为」建立副本。

修改已有图框前，建议先另存为自己的模板文件。

## 放置图框内容

「放置」菜单提供以下绘制工具：

- 「绘制线条」：绘制边框线或标题栏分隔线。
- 「绘制矩形」：绘制矩形边框或表格区域。
- 「绘制文本」：添加说明文字或标题栏文字。
- 「放置位图」：放置位图图像，例如标志。

先确定边框和标题栏的位置，再逐步添加线条、文本和图像。
绘制过程中可缩放查看局部，完成后再检查整张图纸。

## 复用已有内容

- 「放置 → 导入图形」用于导入二维图形文件。
- 「放置 → 添加现有的图框」把其他图框内容追加到当前文件。
- 「放置 → 重置栅格原点」用于恢复栅格原点。

追加内容后，应检查是否出现重复边框、重叠文本或多余图像。
保留需要的对象，再调整当前图框的整体布局。

## 编辑对象

选中需要处理的对象后，可使用「编辑」菜单中的命令：

- 「剪切」「复制」「粘贴」用于移动或复用内容。
- 「删除」用于移除不需要的对象。
- 「全选」用于选择全部对象。
- 「取消全选」用于清除当前选择。
- 「撤消」「重做」用于回退或恢复编辑操作。

处理多个对象前，先确认选中的范围。

## 调整查看范围

「视图」菜单提供「放大」「缩小」和「自适应缩放」。
需要检查局部时，使用「缩放至框选区域」。
需要重新显示画面时，使用「刷新」。

## 设置预览内容

1. 打开「视图 → 图纸预览设置」。
2. 设置用于预览的图纸尺寸和标题栏数据。
3. 检查标题栏中的文本长度、位置及边框布局。
4. 使用不同的预览数据检查文字是否重叠或超出边界。

预览数据用于检查模板效果，实际工程的图纸信息应在相应编辑器中核对。

## 检查与打印

- 「检查 → 显示设计检查器」打开图框的设计检查器。
- 「文件 → 打印」用于打印当前图框。
- 「设置 → 偏好设置」用于调整编辑器相关偏好。

保存前检查边框是否完整、标题栏是否清晰，以及图像和文本的位置。
完成后保存 `.kicad_wks` 文件，并在使用该模板的工程中检查显示效果。
