# 工程管理器（适用版本：KemiCAD 0.9.x）

工程管理器用于创建、打开和整理工程，并启动各个设计工具。
KemiCAD 基于 KiCad，工程文件仍使用原有扩展名。

## 创建与打开工程

1. 选择「文件 → 新建工程」，按对话框提示确定工程名称和位置。
2. 选择「文件 → 打开工程」，打开已有工程。
3. 使用「文件 → 打开最近使用」返回近期处理过的工程。
4. 结束当前工程时，使用「文件 → 关闭工程」。

常见工程文件包括：

- `.kicad_pro`：工程设置。
- `.kicad_sch`：原理图。
- `.kicad_pcb`：PCB 设计。

## 启动设计工具

「工具」菜单提供以下入口：

- 「原理图编辑器」：绘制电路原理图。
- 「符号编辑器」：创建和修改原理图符号。
- 「PCB 编辑器」：进行电路板布局与布线。
- 「封装编辑器」：创建和修改 PCB 封装。
- 「Gerber 查看器」：检查制造输出文件。
- 「计算工具」：打开 PCB 计算器。
- 「图框编辑器」：编辑图纸边框和标题栏。

通常先完成原理图及封装分配，再进入 PCB 设计。
各工具的详细操作见本文末尾的相关文档。

## 版本控制与本地历史

这两个面板默认隐藏，需要时从「视图 → 面板」打开。

- 「版本控制」：显示工程的版本控制面板。
- 「本地历史记录」：显示本地历史面板。

未使用 Git 的工程不显示版本控制面板。
在已有 Git 工程中，可通过「视图 → 面板 → 版本控制」打开该面板。
本地历史面板的准确入口是「视图 → 面板 → 本地历史记录」。

需要恢复历史内容时，使用「文件 → 从本地历史记录中还原工程」。
该命令要求启用相应的本地历史保存方式，并且当前工程已有历史记录。
恢复前先保存或备份当前需要保留的工作。

## 工程文件与归档

- 「视图 → 浏览工程文件」：在文件管理器中打开工程目录。
- 「视图 → 打开文本编辑器」：启动配置的文本编辑器。
- 「文件 → 打包工程」：将工程文件归档。
- 「文件 → 解包工程」：从归档中解出工程文件。

导入其他软件工程时，打开「文件 → 导入非 KemiCAD 工程」。
其中包括「Altium 工程」「Eagle 工程」「PADS 工程」等入口。
请选择与源文件格式对应的入口，并检查导入后的设计。

## 库与设置

- 「设置 → 管理符号库」：维护全局和工程符号库列表。
- 「设置 → 管理封装库」：维护全局和工程封装库列表。
- 「设置 → 配置路径」：设置库等资源使用的路径变量。
- 「设置 → 偏好设置」：调整工具的使用偏好。
