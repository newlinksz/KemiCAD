# PCB 编辑器（适用版本：KemiCAD 0.9.x）

PCB 编辑器用于放置封装、绘制电路板图形、布线、检查设计规则和输出制造文件。
原理图与 PCB 之间的变更需要通过更新操作同步。

## 打开与保存

- 从工程中打开 PCB，可使用与原理图联动的更新功能。
- 独立启动时，「文件」中提供「新建」「打开」和最近使用的文件。
- 使用「文件 → 保存」保存当前电路板。
- 独立启动时可用「另存为」；从工程启动时对应菜单为「保存副本」。
- 「放弃变更」会丢弃当前修改，执行前请确认需要保留的内容已经保存。

## 从原理图开始

1. 先在原理图中完成符号连接和封装分配。
2. 在工程模式下，选择「工具 → 从原理图更新 PCB」。
3. 检查更新内容，再将需要的变更应用到电路板。
4. 根据连接关系摆放封装，随后进行布线。
5. 原理图再次修改后，重新执行更新操作。

独立启动 PCB 编辑器时，「从原理图更新 PCB」不可用。
「工具 → 从 PCB 更新原理图」也需要在工程模式下使用。

## 配置电路板

- 「文件 → 电路板配置」用于设置层、设计规则和默认值。
- 「设置 → 管理封装库」用于配置可用封装库。
- 「视图 → 封装库浏览器」用于浏览库中的封装。
- 「放置 → 放置封装」用于添加封装。
- 「工具 → 从库中更新封装」用于取得封装库中的修改。

## 布线与填充区

- 「布线 → 布线(单端)」用于普通走线。
- 「布线 → 布线(差分)」用于差分对布线。
- 「布线 → 交互布线设置」用于调整交互布线行为。
- 「布线 → 调整单端走线长度」和「调整差分对走线长度」用于长度调整。
- 「放置 → 放置过孔」用于放置独立过孔。
- 「放置 → 绘制填充区」用于建立填充区。
- 「编辑 → 填充所有填充区」用于更新覆铜填充。
- 「编辑 → 取消填充所有填充区」用于移除填充结果。
- 「工具 → 填充区管理器」用于集中管理填充区。

## 查看与检查

- 在「视图 → 面板」中，可打开「属性」「外观」和「网络检查」。
- 使用「视图 → 自适应缩放」调整显示范围。
- 「检查 → 测量工具」用于测量点之间的距离。
- 「检查 → 显示电路板统计报告」用于查看电路板统计信息。
- 「检查 → 设计规则检查」用于检查当前电路板。
- 「检查 → 将封装与库比较」用于查看板上封装与对应库封装的差异。
- 修改布线或填充区后，应重新检查受影响部分。

## 3D 查看

通过「视图 → 3D 查看器」打开三维视图。
KemiCAD 安装包不包含 3D 模型库；封装模型需要另行准备并配置。
模型与库的配置方法见 [符号与封装库](符号与封装库.md)。

## 输出制造文件

完成检查并保存后，在「文件 → 制造输出」中选择所需输出：

- 「Gerbers (.gbr)」：生成 Gerber 文件。
- 「钻孔文件 (.drl)」：生成 Excellon 钻孔文件。
- 「元件定位文件 (.pos, .gbr)」：生成贴装定位文件。
- 「IPC-2581 文件 (.xml)」或「ODB++ 输出文件」：生成相应制造数据。
- 「BOM (物料清单)」：从电路板生成物料清单。

输出后，建议使用 Gerber 查看器核对 Gerber 与钻孔文件。
