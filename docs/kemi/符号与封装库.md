# 符号与封装库（适用版本：KemiCAD 0.9.x）

符号库提供原理图符号，封装库提供 PCB 上的焊盘与外形。
同一器件需要选择合适的符号和封装，并核对引脚与焊盘编号。

## 自带库位置

KemiCAD 安装包包含符号库和封装库。
以下路径均相对于 KemiCAD 的安装目录：

| 资源 | 位置 |
| --- | --- |
| 符号库 | `share\kicad\symbols` |
| 封装库 | `share\kicad\footprints` |

符号库通常是 `.kicad_sym` 文件。
封装库通常是 `.pretty` 文件夹，其中保存 `.kicad_mod` 封装文件。
3D 模型库不随安装包提供，需要另行准备。

## 打开库管理

- 在工程管理器中选择「设置 → 管理符号库」。
- 在工程管理器中选择「设置 → 管理封装库」。
- 相应编辑器的「设置」菜单也提供对应的库管理入口。

库表记录可用库及其路径。
配置库时，应确认磁盘上的库文件或库目录确实存在。

## 全局库与工程专用库

库管理界面包含「全局库」和「工程专用库」。

- 全局库用于多个工程共用的元件资源。
- 工程专用库用于当前工程需要的资源。
- 给当前工程添加专用库时，应先打开该工程。
- 与他人共享工程时，应同时提供所需的自建库。

建议把通用元件放入全局库，把项目专用元件放入工程专用库。
选择库表作用范围后，再添加或调整库记录。

## 添加与检查库记录

1. 打开对应的「管理符号库」或「管理封装库」。
2. 选择「全局库」或「工程专用库」。
3. 添加所需库记录，并核对「名称」「库路径」和「库格式」。
4. 如果路径引用变量，通过「设置 → 配置路径」核对变量值。
5. 确认设置后，在库浏览器中检查资源是否可用。

修改库名称或路径后，应检查已有设计对该库的引用。
暂时找不到元件时，先检查库是否启用及路径是否有效。

## 浏览符号与封装

- 原理图编辑器中使用「视图 → 符号库浏览器」。
- PCB 编辑器中使用「视图 → 封装库浏览器」。
- 在浏览器中选择库和元件，查看相应的符号或封装。

浏览封装时应核对焊盘排列、编号、尺寸和器件方向。
为符号建立封装关联，请使用 [分配封装](分配封装.md) 中的流程。

## 维护自己的库

符号编辑器和封装编辑器均提供「文件 → 新建库」及「文件 → 添加库」。
使用自建库保存修改，可以单独维护自己的元件资源。
符号的制作与检查见 [符号编辑器](符号编辑器.md)。
焊盘和外形的制作与检查见 [封装编辑器](封装编辑器.md)。

库中元件修改后，还应检查原理图或 PCB 中使用的对应元件。
相关编辑器提供从库更新及与库比较的功能。

## 配置 3D 模型

准备需要的 3D 模型库后，打开「设置 → 配置路径」。
核对模型目录变量；具体名称以对话框显示为准。
同时检查封装引用的模型路径与实际文件是否匹配。
然后在 PCB 或封装编辑器中使用「视图 → 3D 查看器」检查结果。

缺少模型时，先检查模型文件、目录变量和封装中的模型关联。
符号库、封装库与 3D 模型库分别使用各自的资源路径。
