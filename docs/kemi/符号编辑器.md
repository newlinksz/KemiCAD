# 符号编辑器（适用版本：KemiCAD 0.9.x）

符号编辑器用于创建和维护原理图符号，包括图形、引脚及符号属性。
符号表示电路中的逻辑连接，实际焊盘形状由对应封装定义。

## 选择或创建符号库

- 「文件 → 新建库」用于创建符号库。
- 「文件 → 添加库」用于添加已有符号库。
- 「设置 → 管理符号库」用于维护全局和工程符号库列表。
- 「文件 → 将库另存为」用于将当前库保存到新文件。

建议把自行制作的符号保存在自建库中，便于维护和共享。
库的配置方法见 [符号与封装库](符号与封装库.md)。

## 创建一个符号

1. 准备要保存符号的库。
2. 选择「文件 → 新建符号」。
3. 使用「文件 → 符号属性」检查符号属性。
4. 使用「放置 → 绘制矩形」等命令绘制符号外形。
5. 使用「放置 → 绘制引脚」添加引脚。
6. 保存并运行符号检查。

已有符号可通过「文件 → 编辑库符号」打开。
编辑前应核对目标库与符号。

## 绘制符号外形

「放置」菜单提供以下绘制工具：

- 「绘制文本」和「绘制文本框」。
- 「绘制矩形」「绘制圆形」和「绘制椭圆」。
- 「绘制弧线」和「绘制椭圆弧」。
- 「绘制线条」「绘制多边形」和「绘制贝塞尔曲线」。

外形应简洁、易读，并为引脚名称和编号留出空间。

## 维护引脚与字段

- 「放置 → 绘制引脚」用于添加引脚。
- 「编辑 → 引脚属性表」用于查看和编辑引脚属性。
- 「编辑 → 符号引脚映射」用于维护符号引脚映射。
- 「编辑 → 更新符号字段」用于更新符号字段。
- 「文件 → 符号属性」用于修改符号的整体属性。

设计时应结合器件资料核对引脚编号与电气含义。
封装焊盘编号也应与原理图符号引脚编号正确对应。

## 检查与保存

1. 选择「检查 → 符号检查器」。
2. 根据检查结果核对符号。
3. 使用「文件 → 保存」保存当前修改。
4. 需要新名称或其他目标库时，使用「文件 → 另存为」。

「另存副本为」用于把当前符号的副本保存到其他库或名称。
编辑库符号时还提供「保存所有」；从原理图进入的符号编辑模式不显示该项。

## 浏览和调整视图

- 「视图 → 面板 → 库结构树」显示或隐藏库结构树。
- 「视图 → 面板 → 属性」显示或隐藏属性面板。
- 「视图 → 符号库浏览器」用于浏览库符号。
- 「视图 → 显示隐藏引脚」用于检查隐藏引脚。
- 「视图 → 显示隐藏字段」用于检查隐藏字段。

「视图 → 自适应缩放」可调整显示范围。
同时打开多个符号时，可使用「下一个符号选项卡」和「上一个符号选项卡」切换。

## 导入与导出

- 「文件 → 导入 → 符号」用于导入符号。
- 「文件 → 导入 → 图形」用于导入图形。
- 「文件 → 导出 → 符号」用于导出符号。
- 「文件 → 导出 → 作为 PNG 查看」用于导出当前视图的 PNG 图像。
- 「文件 → 导出 → 导出符号为 SVG」用于导出 SVG 图像。

图像导出适合制作说明资料；继续编辑符号时应保留符号库数据。
