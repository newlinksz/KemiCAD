# 分配封装（适用版本：KemiCAD 0.9.x）

分配封装工具用于为原理图符号选择 PCB 封装。
分配结果写入符号的封装字段，供后续更新 PCB 使用。

## 打开与准备

1. 在原理图编辑器中打开需要处理的设计。
2. 使用「工具 → 批注原理图」整理符号位号。
3. 选择「工具 → 分配封装」。
4. 在分配前核对器件型号、引脚编号和实际封装要求。

同一个原理图符号可能适用于不同实物封装。
选择时应以器件资料及电路板设计要求为准。

## 准备封装库

- 「设置 → 管理封装库」用于维护封装库列表。
- 「设置 → 配置路径」用于检查库引用的路径变量。
- 「设置 → 管理封装分配文件」用于维护自动分配使用的文件。
- 「设置 → 偏好设置」用于打开偏好设置。

找不到目标封装时，先检查对应库是否已经加入库表。
库文件位置和作用范围见 [符号与封装库](符号与封装库.md)。

## 手动分配

1. 选择需要分配封装的符号。
2. 使用筛选功能缩小候选封装范围。
3. 选择候选封装。
4. 使用「查看选定的封装」检查封装。
5. 执行「分配封装」，然后继续处理其他符号。

检查时应关注焊盘编号、焊盘布局、引脚间距和器件尺寸。
封装名称相近时，也应逐项核对上述参数。

## 筛选候选封装

工具提供以下筛选功能：

- 「使用符号的封装筛选规则」：按符号定义的封装筛选规则筛选。
- 「根据引脚数量筛选」：按引脚数量筛选。
- 「根据封装库筛选」：按封装库筛选。

候选列表中没有目标时，应检查当前筛选条件及可用库。
筛选结果用于缩小范围，最终仍需核对器件资料。

## 查漏与更正

1. 使用「选择下一个未分配封装的符号」查找遗漏项。
2. 必要时使用「选择上一个未分配封装的符号」返回。
3. 分配错误时，可使用「删除封装分配」清除关联后重新选择。
4. 误操作可使用「编辑 → 撤消」，需要恢复时使用「编辑 → 重做」。

工具还提供「删除所有封装分配」。
需要重新处理全部关联时再使用，并先确认当前工作。

## 自动分配

1. 准备符合当前器件命名方式的封装分配文件。
2. 通过「设置 → 管理封装分配文件」配置文件列表。
3. 使用「自动分配封装」执行自动关联。
4. 逐项复核结果，并处理仍未分配的符号。

自动分配使用封装分配文件，根据符号的值建立关联。
完成后仍应确认实际器件封装和焊盘编号。

## 保存并交给 PCB

1. 选择「文件 → 保存到原理图」。
2. 返回原理图编辑器，保存原理图文件。
3. 在工程模式中使用「工具 → 从原理图更新 PCB」。

「保存到原理图」的作用是把分配结果写回原理图符号的封装字段。
完成分配后仍应在原理图编辑器中保存文件，再继续 PCB 工作。
