# 文档索引（适用版本：KemiCAD 0.9.x）

KemiCAD 是基于 KiCad 的中文品牌版。
本目录按工程管理、原理图、PCB 和辅助工具分别提供使用说明。

## 入门与总览

- [入门指南](入门指南.md)：介绍安装、创建工程以及从原理图到制造输出的基本流程。
- [使用帮助](使用帮助.md)：汇总主要工具、常用操作和常见问题。

## 工程与元件库

- [工程管理器](工程管理器.md)：介绍工程打开、工具启动、版本控制、本地历史与归档。
- [符号与封装库](符号与封装库.md)：说明库管理、库浏览器、全局及工程库表和 3D 模型配置。

## 原理图设计

- [原理图编辑器](原理图编辑器.md)：介绍符号连接、层次图纸、电气规则检查和 PCB 更新。
- [符号编辑器](符号编辑器.md)：介绍符号外形、引脚、字段、检查及保存。
- [分配封装](分配封装.md)：介绍候选筛选、手动与自动分配，以及把结果保存到原理图。

## PCB 设计与输出

- [PCB 编辑器](PCB编辑器.md)：介绍电路板配置、布局布线、填充区、检查及制造输出。
- [封装编辑器](封装编辑器.md)：介绍封装库、焊盘、图形、检查及与 PCB 的配合使用。
- [Gerber 查看器](Gerber查看器.md)：介绍制造文件载入、层显示、测量与输出复核。

## 计算与图纸

- [PCB 计算器](PCB计算器.md)：按实际面板说明器件选值、孔径、导体、间距、传输线和参考表。
- [图框编辑器](图框编辑器.md)：介绍图框绘制、内容复用、预览设置、保存与打印。

## 建议阅读顺序

1. 初次使用：入门指南 → 工程管理器 → 符号与封装库。
2. 完成电路设计：原理图编辑器 → 分配封装 → PCB 编辑器。
3. 制作自定义元件：符号编辑器 → 封装编辑器。
4. 准备制造文件：PCB 编辑器 → Gerber 查看器。
5. 按需查阅：PCB 计算器、图框编辑器和使用帮助。

## 按问题查找

- 找不到版本控制或历史面板：查看工程管理器。
- 找不到符号或封装：查看符号与封装库。
- 需要更换器件封装：查看分配封装。
- 原理图修改尚未反映到 PCB：查看原理图编辑器与 PCB 编辑器。
- 需要检查生产输出：查看 Gerber 查看器。
- 需要计算线宽、孔径或传输线参数：查看 PCB 计算器。
- 需要调整图纸边框和标题栏：查看图框编辑器。

## 阅读约定

菜单路径用「上级菜单 → 命令」表示，省略助记符标记和结尾省略号。
部分菜单随工具的独立启动或工程启动方式变化，详见对应文档。
安装包包含符号与封装库；3D 模型需要另行准备。
