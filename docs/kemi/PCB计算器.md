# PCB 计算器（适用版本：KemiCAD 0.9.x）

PCB 计算器提供器件选值、导体尺寸、间距、传输线和常用参考表。
从左侧树状列表选择计算面板，再在右侧输入参数或查看表格。

## 开始使用

1. 选择与当前设计问题对应的面板。
2. 先核对输入框旁的单位，再填写数值。
3. 有「计算」按钮的面板，在输入完成后点击「计算」。
4. 传输线面板使用「分析」或「合成」完成相应计算。
5. 记录结果以及使用的材料、温度、频率等条件。

## 通用系统设计

### 稳压器

- 支持带独立反馈端的标准类型和三端稳压器类型。
- 根据参考电压、电阻和相关参数计算输出电压或所选未知量。
- 可管理稳压器参数数据文件，并查看容差计算结果。

### 电阻计算器

- 根据目标阻值，在所选 E 系列中寻找电阻组合。
- 支持排除两个不可用阻值。
- 显示组合方案及近似误差，便于比较选值。

## 封装设计

### Through-hole Size（通孔尺寸）

- 根据引脚形状及尺寸范围，计算建议的孔径和焊盘尺寸。
- 可选择孔径标准、等级、取整方式和焊环尺寸。
- 通过示意图检查引脚、孔和焊盘之间的尺寸关系。

## 电源、电流和隔离

### 电气间距

- 包含「IPC 2221」和「IEC 60664」两个页面。
- 前者用于查看电气间距，后者提供电气间隙和爬电距离计算。
- 按页面要求填写电压、绝缘类型、污染等级、材料和海拔等条件。

### 过孔外径

- 输入成品孔径、镀层厚度、过孔长度和焊盘尺寸等参数。
- 查看电阻、压降、功耗、估算载流能力及寄生参数。
- 页面出现尺寸关系提示时，先检查输入的几何尺寸。

### 走线宽度

- 根据电流、允许温升和铜厚等参数估算走线尺寸。
- 分别显示外层走线和内层走线的计算结果。
- 同时可查看截面积、电阻、压降和功耗。

### 熔断电流

- 使用环境温度、熔点、走线宽度、厚度、电流和熔断时间等参数。
- 选择要计算的量，输入其余已知条件后点击「计算」。
- 结合页面内的说明理解所用模型和适用条件。

### 线缆尺寸

- 可选择标准线径，查看直径、截面积和相关导体参数。
- 根据温度、电流和长度计算直流电阻、压降及功耗。
- 输入的长度应包含回流路径。

## 高速

### 波长

- 换算频率、周期以及真空和介质中的波长。
- 可设置相对介电常数和相对磁导率，查看介质中的传播速度。

### RF 衰减器

- 选择衰减器结构，填写衰减量和输入、输出阻抗。
- 点击「计算」，查看电阻值及页面显示的提示。

### 传输线

- 支持微带线、耦合微带线、带状线、耦合带状线等结构。
- 也提供共面波导、带地平面的共面波导、矩形波导、同轴线和双绞线。
- 使用「分析」根据物理尺寸计算电气参数。
- 使用「合成」根据目标电气参数求解相应物理尺寸。

## 备忘录

- **E 系列**：查看常用标准数值系列，辅助电阻等器件选值。
- **色环电阻**：按容差类别查看数值、倍率和容差色环对照。
- **电路板类别**：查看不同类别的线宽、间距及焊盘尺寸差参考表。
- **电偶腐蚀**：比较金属间的电位差，可设置阈值及材料名称显示方式。

## 使用结果

计算结果与输入条件有关；修改铜厚、材料或温度后，应重新检查相关结果。
将确认后的参数用于 PCB 或封装设计，并结合制造条件复核尺寸。
对于带有内置说明的面板，可先阅读页面中的公式和说明。
