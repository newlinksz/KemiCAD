# Gerber 查看器（适用版本：KemiCAD 0.9.x）

Gerber 查看器用于打开和检查 Gerber、钻孔及相关制造文件。
建议在交付制造文件前，将输出文件重新载入并检查层间关系。

## 打开制造文件

「文件」菜单提供以下入口：

- 「打开 Gerber 绘制文件」：在新层上载入 Gerber 文件。
- 「打开 Excellon 钻孔文件」：在新层上载入钻孔文件。
- 「打开 Gerber Job 文件」：载入作业文件及其关联的 Gerber 文件。
- 「打开 Zip 归档文件」：载入包含 Gerber 和钻孔文件的 ZIP 归档。
- 「打开自动检测到的文件」：自动检测文件类型后打开。

Gerber、钻孔、Job 和 ZIP 文件分别有最近使用记录。
可通过各文件类型的最近打开记录重新打开文件。

## 建议的检查顺序

1. 打开需要检查的 Gerber 文件。
2. 打开对应的钻孔文件。
3. 选择「视图 → 显示层管理」，检查已载入的层。
4. 使用「视图 → 自适应缩放」查看整体。
5. 放大关键位置，检查图形、孔位和层间关系。
6. 需要核对尺寸时，使用「工具 → 测量工具」。

应确认所有文件来自同一次输出，避免混用不同版本的文件。

## 缩放、栅格与单位

- 「视图 → 放大」和「视图 → 缩小」用于调整显示比例。
- 「视图 → 缩放至框选区域」用于查看指定区域。
- 「视图 → 刷新」用于刷新画面。
- 「视图 → 显示栅格」用于切换背景栅格。
- 「视图 → 极坐标」用于切换坐标显示方式。
- 在「视图 → 单位」中，可选「英寸 (Inches)」「密尔 (mil)」或「毫米 (mm)」。

## 图形显示方式

- 「视图 → 线条草图」以轮廓方式显示线条。
- 「视图 → 多边形草图」以轮廓方式显示多边形。
- 「视图 → 曝光草图项目」以轮廓方式显示曝光项目。
- 「视图 → 显示 D 码」用于显示 D 码编号。
- 「视图 → 重影显示负片对象」用于以重影颜色显示负片对象。
- 「视图 → 以强制不透明度模式显示」用于调整层叠显示方式。
- 「视图 → 以 XOR 模式显示」用于以异或方式比较重叠图形。
- 「视图 → 翻转 Gerber 视图」用于镜像查看。

切换显示方式后，应留意当前状态，区分显示效果与文件内容。

## 查看文件信息

- 「工具 → 列出 D 码」用于查看 Gerber 文件中定义的 D 码。
- 「工具 → 显示源码」用于查看当前层对应的源文件。
- 「工具 → 测量工具」用于交互式测量两点之间的距离。

检查文件内容时，可结合图形显示、D 码列表和源文件一起核对。

## 重新加载与清除

- 制造文件重新生成后，可使用「文件 → 重新加载所有层」。
- 「工具 → 清除当前层」用于移除当前层的显示内容。
- 「文件 → 清除所有层」用于清空已载入的层。
- 检查另一套输出前，建议先清空原有层，再载入新的文件。

## 导出与打印

「文件 → 导出到 PCB 编辑器」可将数据导出为 KemiCAD PCB 文件。
导出后，应在 PCB 编辑器中检查所得文件。
「文件 → 打印」用于打印当前查看内容。
