# KemiCAD 入门指南

适用版本：KemiCAD 0.9.x（Windows x64）。KemiCAD 基于 KiCad 开源软件，操作方式与 KiCad 基本一致，默认中文界面。

## 1. 安装

1. 在 [Releases](https://github.com/newlinksz/KemiCAD/releases) 页面下载 `KemiCAD-x.y.z-x64-setup.exe`。
2. 双击运行，按提示安装（需要管理员权限），默认安装到 `C:\Program Files\KemiCAD`。
3. 安装完成后，从开始菜单或桌面快捷方式启动 KemiCAD。

## 2. 首次启动

首次启动会出现设置向导，可选择导入已有设置或使用默认设置，并配置元件库。一般直接使用默认设置即可，之后可在「设置」中修改。

## 3. 创建工程

1. 在主窗口选择「文件 → 新建工程」，选择保存位置并输入工程名。
2. 工程包含：工程文件 `.kicad_pro`、原理图 `.kicad_sch`、PCB `.kicad_pcb`。
3. 在主窗口右侧点击「原理图编辑器」或「PCB 编辑器」打开对应文件。

## 4. 从原理图到 PCB

1. **绘制原理图**：在原理图编辑器中放置符号（快捷键 `A`）、连线（`W`）、放置电源符号（`P`）、添加网络标签（`L`）。
2. **批注**：使用「工具 → 批注原理图」给元件自动编号。
3. **电气规则检查（ERC）**：「检查 → 电气规则检查 (ERC)」，修正报告的错误。
4. **分配封装**：「工具 → 分配封装」，为每个符号选择封装。
5. **更新到 PCB**：在原理图中选择「工具 → 从原理图更新 PCB」（快捷键 `F8`），元件会导入 PCB 编辑器。
6. **布局布线**：在 PCB 编辑器中绘制板框（`Edge.Cuts` 层），摆放元件，布线（`X`），铺铜（放置填充区域，按 `B` 填充所有区域）。
7. **设计规则检查（DRC）**：「检查 → 设计规则检查」，修正问题。

## 5. 输出生产文件（Gerber）

1. 在 PCB 编辑器中选择「文件 → 制造输出 → Gerbers (.gbr)...」打开绘制对话框。
2. 选择需要的层（铜层、阻焊、丝印、`Edge.Cuts` 等）和输出目录，点击「绘制」。
3. 在同一对话框中点击「生成钻孔文件」输出钻孔文件。
4. 可用「Gerber 查看器」检查输出结果后再交给板厂。

原理图可通过「文件 → 绘制」输出 PDF/SVG 等格式；物料清单（BOM）可通过原理图编辑器的「工具 → 生成物料清单」导出。

## 6. 元件库位置

- 安装包已包含 **KemiCAD 元件库**（符号库和封装库），位于安装目录的 `share\kicad\symbols` 和 `share\kicad\footprints`。
- 可在「设置 → 管理符号库 / 管理封装库」中查看、添加或移除库。

## 7. 3D 模型

安装包不包含 3D 模型库。如需在 3D 查看器中显示元件模型，请自行准备 3D 模型库（包含各个 `.3dshapes` 文件夹的目录），然后在「设置 → 配置路径」中把 `KICAD*_3DMODEL_DIR` 变量（如 `KICAD10_3DMODEL_DIR`，以对话框中显示的名称为准）指向该目录。
