# 封装编辑器（适用版本：KemiCAD 0.9.x）

封装编辑器用于创建和修改封装，包括焊盘、图形、文本及封装属性。
制作封装时，应以器件数据手册中的尺寸和引脚定义为依据。

## 准备封装库

- 「文件 → 新建库」用于创建新的库文件夹。
- 「文件 → 添加库」用于添加已有库。
- 「设置 → 管理封装库」用于编辑全局与工程封装库列表。
- 建议将自建封装保存在自己的库中。
- 库的位置和使用范围见 [符号与封装库](符号与封装库.md)。

## 新建或打开封装

1. 选择「文件 → 新建封装」，创建空白封装。
2. 需要通过向导生成时，选择「文件 → 创建封装」。
3. 修改已有库封装时，选择「文件 → 编辑库封装」。
4. 使用「文件 → 封装属性」检查封装的整体属性。
5. 完成编辑后保存，并核对目标库和封装名称。

「新建封装」创建空白封装，「创建封装」打开封装向导。

## 焊盘与编号

- 「放置 → 添加焊盘」用于放置焊盘。
- 「编辑 → 焊盘表」用于批量编辑焊盘。
- 「编辑 → 为焊盘重新编号」可按点击顺序重新编号。
- 焊盘编号应与原理图符号的引脚编号对应。
- 修改编号后，应重新核对器件方向与引脚定义。

## 图形、文本与锚点

- 「放置 → 绘制线条」用于绘制线条图形。
- 「放置 → 绘制文本」用于添加文本。
- 「放置 → 绘制规则域」用于建立规则域。
- 「放置 → 放置封装锚点」用于设置封装的坐标锚点。
- 「编辑 → 编辑文本与图形属性」用于统一调整文本和图形属性。
- 「编辑 → 批量编辑封装字段」用于编辑库中封装的字段表。

## 查看与检查

- 「视图 → 面板 → 库结构树」用于显示或隐藏库结构树。
- 「视图 → 面板 → 属性」用于显示或隐藏属性面板。
- 「视图 → 面板 → 外观」用于显示或隐藏外观面板。
- 「视图 → 封装库浏览器」用于浏览可用封装。
- 「视图 → 自适应缩放」用于调整显示范围。
- 「检查 → 测量工具」用于测量点之间的距离。
- 「检查 → 封装检查器」用于检查当前封装。
- 「工具 → 清理图形」用于清理冗余图形项目。
- 「工具 → 修复封装」会运行诊断并尝试修复封装。

检查结果应结合数据手册复核，特别是焊盘编号、尺寸和器件方向。

## 与电路板配合使用

- 「工具 → 从当前 PCB 加载封装」用于加载当前电路板上的封装。
- 「工具 → 在 PCB 上插入封装」用于将封装插入当前电路板。
- 编辑库封装后，可在 PCB 编辑器中使用「从库中更新封装」。
- 应确认当前修改的是库中的封装，还是从电路板加载的封装。

## 保存、导入与导出

- 「文件 → 保存」保存当前变更。
- 「文件 → 另存为」将当前封装另存。
- 「文件 → 导入 → 封装」用于从文件导入封装。
- 「文件 → 导入 → 图形」用于导入二维图形。
- 「文件 → 导出 → 封装」用于将当前封装导出到文件。
- 「文件 → 打印」用于打印当前内容。

## 3D 查看

使用「视图 → 3D 查看器」查看封装的三维显示。
KemiCAD 安装包不附带 3D 模型库；需要的模型须另行准备并配置。
